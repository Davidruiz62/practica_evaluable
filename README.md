# practica_evaluable

## Descripción del proyecto

Proyecto realizado para la práctica evaluable de Documentación y Control de Versiones del curso 2DAW 2025-2026.

La aplicación consiste en una página web sencilla creada para practicar el uso de Git, GitHub y documentación técnica.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

---

## Instalación

1. Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

2. Abrir el proyecto en Visual Studio Code.

3. Ejecutar el archivo `index.html`.

---

## Despliegue

El proyecto puede desplegarse utilizando:

- Servidor local
- XAMPP
- Apache HTTP Server
- Nginx
- GitHub Pages
